# 錨題

錨題是「答案已知」的評分練習。正式評分前，SinoBee 先拿錨題問評鑑模型；答錯的評鑑模型會在報告中被標示，避免太寬鬆或看不懂標準的評鑑模型默默影響分數。

格式（`out/anchors.json`）：
```json
[
  {"rubric": "每項決議都能在逐字稿中找到依據。",
   "content": "逐字稿：決定下週發布。\n紀錄：決議：下週發布。",
   "expect": true},
  {"rubric": "每項決議都能在逐字稿中找到依據。",
   "content": "逐字稿：決定下週發布。\n紀錄：決議：下週發布、預算加倍。",
   "expect": false}
]
```

寫法：
- `rubric` 直接用你題組裡 `llm` 題的標準。
- `content` 短（幾行就好），一看就知道該不該通過；不要模稜兩可。
- 至少 3 題，同時要有 `expect: true` 與 `expect: false`。
- 不通過的例子要接近真實的錯誤（多寫了沒依據的內容、漏了必要欄位），不要只是空白。
- 內容一樣要虛構或去識別。
