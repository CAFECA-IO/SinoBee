# 報告範本（report.md）

報告寫在影片資料夾裡的 `report.md`，圖片用相對路徑（`cover.png`、`frames/tMMSS.jpg`），整個資料夾就能直接搬走或轉成網頁。用使用者的語言寫（預設繁體中文）；影片原文的引述保留原文短句，必要時附翻譯。

照下面的骨架寫，`<...>` 換成內容，不要留下尖括號或「待補」。

```markdown
# <影片在講什麼的一句話標題，不必照抄原標題>

![封面](cover.png)

> <一句話摘要：這部影片主張或呈現了什麼，給誰看>

## 影片資訊

| 項目 | 內容 |
|---|---|
| 原標題 | <原標題> |
| 頻道 | <頻道>（<訂閱數，若有>） |
| 發布日期 | <YYYY-MM-DD> |
| 長度 | <mm:ss> |
| 觀看數 | <數字>（擷取於 <今天日期>） |
| 分類 | <中文名> · <English> |
| 連結 | <https://www.youtube.com/watch?v=ID> |

## 這部影片在說什麼

<3–5 段。第一段講主題與結論；之後依影片的順序講主要內容，像在跟沒看過的人轉述。引用畫面時嵌入截圖：>

![<這張圖呈現的東西>](frames/t0335.jpg)

## 重點時間軸

- [00:00](https://www.youtube.com/watch?v=ID&t=0s) <這段在講什麼>
- [03:35](https://www.youtube.com/watch?v=ID&t=215s) <...>
- <5–12 個時間點；有章節就沿用章節>

## 分類分析：<中文名>

<依 references/categories.md 該分類的問題寫成段落，每個判斷附時間戳。>

## 論述查核

<只有需要查核的分類寫這節（見 categories.md）。照 references/fact-check.md 的表格與判定詞。>

| # | 時間 | 影片中的說法 | 判定 | 查核說明 | 來源 |
|---|---|---|---|---|---|
| 1 | [mm:ss](...) | 「...」 | 正確 | ... | [來源名稱](https://...) |

**整體評估：** <這部影片的論述整體可信度與最大的問題。>

## 觀點、偏誤與盲點

<講者立場、可能的利益衝突、沒說的事、適合與不適合的觀眾。不查核的分類也寫：例如業配、刻板印象、資訊過時。>

## 結論

<2–3 段：值不值得看、適合誰、看完該記住什麼、該保留什麼懷疑。健康或財經內容在這裡加免責說明。>

## 資料來源與方法

- 影片資料：YouTube 頁面、<人工字幕 / 自動字幕 / 無字幕> 逐字稿（語言 <xx>）、每約 <N> 秒一張的畫面截圖。
- 查核來源：<列出所有用到的網址>
- 限制：<例如自動字幕可能有錯字、截圖解析度低、未能取得的資料>
- 報告產生：SinoBee youtube-analysis 技能，<今天日期>。
```

寫作要求：
- 摘要和分析要能讓沒看影片的人理解；不要逐句翻譯逐字稿。
- 每個重要判斷都能回溯到時間戳或來源。
- 引用歌詞、劇本等創作內容時只用短句。
- 截圖選真正有資訊的畫面（圖表、示範、關鍵場景），每張附說明文字；全篇 2–6 張即可。需要特定時刻的畫面用 `frame <folder> <mm:ss>` 擷取。
