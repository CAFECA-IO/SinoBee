# 16 種影片分類與分析重點

先看完逐字稿與畫面，再選**一個**主分類（`cover.json` 的 `category` 填英文 key）。影片橫跨兩類時，選「觀眾最後帶走的是什麼」那一類，另一類寫進「分類分析」的一小段。

查核等級：
- **全面**：凡是撐起論點的事實陳述都要查（至少 3 則）。
- **重點**：只查關鍵的數字、人名、日期、規格、醫療與財務說法（至少 1 則）。
- **不查核**：改寫創作與內容分析；但影片若出現醫療、財務、時事的事實說法，仍照「重點」查。

報告的分析段落標題必須是 `## 分類分析：<中文名>`，例如 `## 分類分析：知識科普`。

| key | 中文名 | 辨識線索 | 查核 |
|---|---|---|---|
| news | 新聞時事 | 報導最近發生的事件、記者或主播、引用官方與現場畫面 | 全面 |
| politics | 政治評論 | 對政策、政黨、選舉、國際關係表態或論證 | 全面 |
| science | 知識科普 | 解釋科學、歷史、數學或社會知識的原理 | 全面 |
| tutorial | 教學實作 | 一步一步教人完成一件事（軟體、料理、手作、考試） | 重點 |
| review | 開箱評測 | 介紹或比較商品、服務、App，給出推薦 | 重點 |
| finance | 財經投資 | 市場、個股、加密貨幣、理財、總經 | 全面 |
| health | 醫療健康 | 疾病、藥物、飲食、運動、心理健康 | 全面 |
| tech | 科技趨勢 | AI、半導體、產業與產品發展、未來預測 | 全面 |
| interview | 訪談對談 | Podcast、專訪、圓桌，多人對話為主 | 重點 |
| talk | 演講講座 | TED、發表會、課堂、研討會的單人演講 | 重點 |
| documentary | 紀錄片 | 以敘事記錄真實人物、事件或議題 | 全面 |
| vlog | 生活 Vlog | 創作者記錄自己的生活、工作或日常 | 不查核 |
| travel-food | 旅遊美食 | 景點、行程、餐廳、料理探店 | 重點 |
| gaming | 遊戲電競 | 實況、攻略、賽事、遊戲評論 | 不查核 |
| music | 音樂表演 | MV、現場演出、翻唱、樂器演奏 | 不查核 |
| entertainment | 娛樂戲劇 | 綜藝、喜劇、短劇、電影預告與解說、動畫 | 不查核 |

## 各分類的分析段落

每一類回答下面的問題，用段落寫成，不要只列點；每個判斷都附上時間戳（`[mm:ss](https://www.youtube.com/watch?v=ID&t=秒s)`）。

### 新聞時事 news
- 事件的 5W1H 交代完整嗎？哪些資訊缺席（另一方說法、數據來源、時間點）？
- 消息來源是誰：官方、目擊者、匿名、其他媒體轉述？可信度如何？
- 報導和評論有沒有分開？標題與縮圖是否誇大內文？
- 對照其他媒體或官方資料，影片發布後事件是否有新進展、更正？

### 政治評論 politics
- 主要論點與論證結構：前提、證據、結論各是什麼？
- 證據是否支撐結論：選擇性引用、以偏概全、稻草人、訴諸情緒、滑坡等謬誤。
- 立場與利益：頻道背景、可能的贊助或政治傾向；有無呈現對立觀點。
- 把「事實陳述」和「價值判斷」分開；只查核前者，後者標為「觀點」。

### 知識科普 science
- 講解的概念是否正確、簡化是否造成誤解？標出「為了好懂而簡化」與「說錯」的差別。
- 有沒有引用研究或資料？研究是否被誇大（相關說成因果、動物實驗說成人類效果）？
- 內容是否過時：之後的研究或定義有無更新？
- 教學設計：比喻、視覺化、節奏是否幫助理解。

### 教學實作 tutorial
- 步驟能否照做重現？前置條件、版本、工具是否交代？
- 有無錯誤、危險或已過時的步驟（軟體版本、安全規範）？
- 列出做完需要的時間、成本與常見失敗點。
- 適合的程度：新手、進階？

### 開箱評測 review
- 規格、價格、上市日期等可查事實是否正確。
- 測試方法：有實測還是只讀規格？樣本與比較對象是否公平？
- 業配與利益揭露：是否標示贊助、聯盟連結、廠商提供？
- 優缺點是否平衡；結論是否和展示的證據一致。

### 財經投資 finance
- 數據（價格、報酬率、總經數字、財報）是否正確且標明時間點。
- 論點的邏輯：是否把過去績效當未來保證、倖存者偏差、忽略風險與成本。
- 推薦是否有利益衝突（持倉、付費課程、平台推廣）。
- 報告結尾加一句：本分析不構成投資建議。

### 醫療健康 health
- 醫療說法是否符合現行指引或系統性回顧（WHO、衛福部、CDC、Cochrane、主要醫學會）。
- 證據等級：個案、小型研究、動物實驗、統合分析？效果大小是否被誇大？
- 講者資格與利益：是否銷售產品、補充劑。
- 可能造成的傷害：延誤就醫、停藥、劑量錯誤。報告結尾加一句：本分析不構成醫療建議，請諮詢醫療專業人員。

### 科技趨勢 tech
- 技術描述是否正確；規格、時程、市占、融資等數字是否可查。
- 預測與事實分開：哪些是已發生、已公布，哪些是推測。
- 炒作檢查：把展示當量產、把路線圖當交付。
- 影片之後的發展（產品是否上市、數字是否更新）。

### 訪談對談 interview
- 誰在說話、各自的背景與立場。
- 主要觀點與最有價值的見解；主持人是否追問。
- 來賓提出的關鍵事實說法（重點查核）。
- 對話中被迴避或沒講清楚的問題。

### 演講講座 talk
- 核心論點與結構（開場鉤子、論證、結論）。
- 講者用了哪些證據、案例、數據（重點查核）。
- 表達與簡報技巧：哪些地方特別有效。
- 適合誰看、看完能帶走什麼。

### 紀錄片 documentary
- 敘事立場：誰的視角？誰沒有被訪問？
- 歷史與事實細節是否正確；重建畫面或戲劇化處理是否有標示。
- 剪輯與配樂如何引導情緒與結論。
- 與其他報導、文獻對照的差異。

### 生活 Vlog vlog
- 內容主線與情緒基調；創作者想傳達的生活態度或價值。
- 敘事與剪輯：節奏、鏡頭、字幕、配樂。
- 業配或置入的出現方式與揭露。
- 觀眾能得到什麼（陪伴感、資訊、靈感）。

### 旅遊美食 travel-food
- 地點、價格、營業時間、交通等實用資訊（重點查核，並註明可能已變動）。
- 體驗描述是否具體；是否有招待或業配。
- 適合的旅客類型、預算與季節。
- 整理成可直接使用的清單（地點、預算、注意事項）。

### 遊戲電競 gaming
- 遊戲與版本、玩法或賽事背景。
- 攻略類：技巧是否正確、版本是否仍適用。
- 實況與賽事：精彩時刻、戰術分析、結果。
- 娛樂效果與社群互動。

### 音樂表演 music
- 作品資訊：歌手、詞曲、編曲、發行背景。
- 音樂分析：曲式、編曲、演唱或演奏技巧、製作。
- 視覺與 MV 敘事：意象、色彩、剪輯與歌詞的呼應。
- 歌詞主題（只引用短句，不轉載整段歌詞）。

### 娛樂戲劇 entertainment
- 內容概要與笑點、劇情或解說的主軸（電影解說要標示劇透）。
- 表演、剪輯、節奏的效果。
- 是否涉及刻板印象、冒犯或爭議。
- 目標觀眾與觀看建議。
